# Frozen public results

These compact tables are exported from the completed `final_test_v1` evaluation. They contain aggregate metrics and one representative score timeline, not the Kaggle source data.

- All six models use the same group-held-out Test split.
- Thresholds were selected on Validation and frozen before Test.
- No point adjustment was used.
- `representative_m6_timeline.csv` contains overlapping-window labels and scores for visualization only.

The internal experiment archive retains checkpoints, detailed window errors, manifests, and hashes. Those larger or dataset-derived artifacts are intentionally excluded from the public repository.
